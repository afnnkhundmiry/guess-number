# Number Guessing Game 🔢🎯

A simple Java-based number guessing game where the computer randomly picks a number and the user has to guess it.

## 🎮 How It Works
- The computer picks a random number between 1 and 100.
- You try to guess it.
- The game gives you hints ("too high" or "too low") until you guess correctly.

## 📦 Features
- Console-based interaction
- Random number every time
- Displays the number of attempts taken
